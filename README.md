# VibeColorizer

## Что это?
Аддон для модификации Яндекс музыки [PulseSync](https://github.com/PulseSync-LLC/PulseSync-client)

> **⚠️ ВАЖНО: Для работы 6-цветного режима (Multi) ОБЯЗАТЕЛЬНО нужен патч `patch-vibe-colors.js`**
>
> Без патча PulseSync **не читает** CSS-переменные `--pulsesync-vibe-custom-colors` и волна не меняет цвет в 6-цветном режиме.
> Аддон будет писать переменные, но визуального эффекта не будет.
>
> **Установка патча:**
> 1. Скачай `patch-vibe-colors.js` из [репозитория Github](https://github.com/backundotapbut/Pulsesync-Patch-For-VibeColorizer)
> 2. Закрой Яндекс Музыку
> 3. В консоли (PowerShell/cmd):
>    ```cmd
>    cd <папка-с-скриптом>
>    node patch-vibe-colors.js
>    node sync-pulsesync-state.js --force
>    ```
> 4. Запусти Яндекс Музыку
>
> **Legacy / Монотонный режим (1 цвет через CSS-фильтры)** работает **без патча**.
> В настройках выбери `Color Mode: Mono` или `Auto` (если патча нет — сам переключится на 1 цвет).
>
> ---

Аддон для PulseSync, заменяющий палитру анимации «Волны» на доминантные цвета обложки трека.

---

## Возможности

- **До 6 цветов** — полная поддержка всех стопов шейдера волны (требует `patch-vibe-colors.js`)
- **Умный приоритет оттенков** — оранжево-жёлтые (15–60°) → зелёные (60–180°) → остальные
- **Монотонный режим** — один цвет через CSS-фильтры (`hue-rotate`/`saturate`/`brightness`), работает **без патча**
- **Авто-режим** — сам выбирает 6 цветов (если патч есть) или 1 цвет (если нет)
- **Возврат стандартных цветов на паузе** — волна восстанавливает исходный вид, при продолжении цвета применяются снова
- **Прозрачный фон волны** — убирает градиентный фон (`background: transparent`)
- **Предзагрузка обложек** — мгновенная смена цвета при переключении трека
- **Кэш палитр** — до 300 обложек, автоматическая очистка

## Настройки

### Режим работы (верхний блок)
| Параметр | Описание |
|---|---|
| **Патч установлен** | ВКЛ — если сделали шаг 2. В режиме Auto включит 6 цветов. |
| **Режим цвета** | `Auto` (6 если патч есть, иначе 1) · `Multi` (принудительно 6, нужен патч) · `Mono` (принудительно 1 цвет) |
| **Возврат к стандартным на паузе** | При паузе волна становится стандартной, при Play — ваши цвета снова |
| **Включить VibeColorizer** | Глобальное вкл/выкл |

### Извлечение цветов
| Параметр | Описание |
|---|---|
| **Количество цветов** | 1–6 доминантных цветов |
| **Алгоритм выбора** | `Приоритет тёплых` (оранж/жёлт → зелёные → остальные) · `Взвешенный` · `По насыщенности` · `По частоте` · `По кластеру` |
| **Мин. насыщенность** | 0–0.5. 0 = не отбрасывать серые/белые. Чёрный (l≈0) всегда исключён |
| **Мин./Макс. яркость** | Диапазон допустимой светлости. Для белых обложек: макс. 0.99–1.0 |
| **Квантование / Кластеризация** | Точность группировки пикселей |

### Коррекция цветов
Поворот оттенка, усиление насыщенности/яркости, длительность перехода.

### Однотонный режим (настройки фильтра)
Метод извлечения (Default/Balanced/Alternative), интенсивность `hue-rotate`, насыщенность, яркость, адаптивная яркость, спец. режим для нейтральных, предпочтение насыщенности.
- **Полная интенсивность hue-rotate** — ВКЛ = точный цвет (не снижать intensity для больших дельт)

### Прочее
| Параметр | Описание |
|---|---|
| **Полная интенсивность hue-rotate** | Не снижать intensity для больших разностей hue (точный цвет) |
| **Прозрачный фон волны** | Убирает градиентный фон (`background: transparent`) |
| **Предзагрузка обложек** | Загружает следующий трек заранее |
| **Размер кэша** | Макс. кэшируемых палитр (20–300) |
| **Режим отладки** | Логи в консоли (F12) |

## Требования

- PulseSync
- Для 6 цветов: `patch-vibe-colors.js` (см. установку)
- Конфликтующие аддоны отключить: `vibecolorizer-and-lamps`, `wavecolorizer-webgl-001` (переименуйте `metadata.json` → `metadata.json.disabled`)
